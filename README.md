# ⚡ Guía de Despliegue en Vercel - Panel Admin

Esta carpeta contiene la versión optimizada de tu **Panel de Administración en Tiempo Real** lista para estar en vivo en [Vercel.com](https://vercel.com) en menos de 30 segundos.

---

### 🚀 Opción 1: Despliegue con 1 Clic usando Vercel CLI (Más rápido)

1. Abre tu consola de PowerShell o CMD.
2. Navega a esta carpeta:
   ```bash
   cd c:\xampp\htdocs\Pruebas\jj\vercel_admin
   ```
3. Ejecuta el comando de Vercel:
   ```bash
   npx vercel
   ```
4. Presiona `Enter` a todo y en **15 segundos** Vercel te entregará tu enlace en vivo con SSL ilimitado (ejemplo: `https://panel-admin.vercel.app`).

---

### 🌐 Opción 2: Despliegue mediante GitHub / Vercel Dashboard

1. Sube el contenido de esta carpeta `vercel_admin` a un repositorio en GitHub.
2. Entra a [vercel.com/new](https://vercel.com/new).
3. Importa tu repositorio.
4. Presiona **Deploy**.

---

### 🎛️ Características del Panel en Vercel:
* **Latencia Ultra Baja (Vercel Edge):** Servido globalmente en milisegundos.
* **Conexión en Vivo a Firebase:** Recibe cada letra y número digitado al instante.
* **Alertas Sonoras Sintetizadas:** Funciona con Web Audio API en cualquier dispositivo móvil o PC.
* **Acciones Remotas:** Los 9 botones de control (OTP, SMS, Clave Dinámica, CVV, Error, Reiniciar, Cerrar, Eliminar).
